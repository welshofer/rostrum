# Audit record

[REPORT.md](REPORT.md) records the original findings; [CHANGELOG.md](CHANGELOG.md)
records the approved implementation, validation and remaining limits.
[PERFORMANCE.md](PERFORMANCE.md) records the measured baseline.

Committed evidence includes incremental diffs, synthetic preview captures, app
result summaries, benchmark timings and fixture-generation source. Generated
PPTX/SVG/PNG fixtures, executables, compiler caches, raw local logs and local
session-discovery indexes remain ignored scratch files. Links to those files in
the reports describe the original local evidence and may not resolve in a fresh
checkout. The production benchmark and test instructions are in
[Tools/rostrum-benchmark](../Tools/rostrum-benchmark/README.md).
