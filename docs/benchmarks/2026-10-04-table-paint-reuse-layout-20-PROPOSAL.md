# S20 finite performance proposal

This proposal compares operation-local shared-border paint reuse against accepted S19, with whole-output identity required. The baseline is the retained matching Release build of Sources `11ead6fd725008f26757f839abda10aa97761adb`, including S15 ordinary inherited-style reuse. The prototype worker branch and its Debug objects are not the formal baseline.

Keep all 594 original children and all original inputs, fonts, drivers, iteration counts and measured scopes. Add exactly three separately labeled controls (66 children): unique direct borders at 200×50, partial template-budget admission at 20×10, and complete oversized-template bypass at 6×6. This yields 660 children, 31 primary comparisons and all 339 phase comparisons. Each workload has one excluded warmup pair and ten retained alternating pairs.

The direct control measures the unavoidable identity lookup and non-admission path at scale. The 20×10 control uses 40,000-character unknown comments on six style lines to exhaust the estimated 1 MiB template budget after some admissions. The 6×6 control uses 1,100,000-character comments to reject every template. The latter stays small to bound repeated large-subtree copying. These are estimated template-budget controls; the 216-entry paint-cache cap has separate unit coverage. Untimed preflight must confirm the intended admission paths before final freeze.

The three helpers and canonical runner remain byte-identical to S19. Font registration and verification stay outside render timing. Each file renders the original source before edit/save phases; there is no extra fitting pass. The new controls use the existing table helper and unchanged DejaVu face bytes. The original 594 children remain a distinct pool for comparison with S19 scope.

Expected preservation inventory is 190 cases / 886 slides. Require complete SVG, ordered diagnostics, inheritance and package identity across baseline and two candidate runs, plus independent package reopen. Preserve every fill, stroke, glyph and text attribute; no stripping or counterfactual is appropriate for this output-preserving change. Retain all native references, 101,310 shaping records, 1,728 layout records, and small/large/image-heavy preservation. Stress inputs add no native fidelity claim.

After root supplies integrated source, verify the approved three-production-file delta and intact ordinary-style reuse, run full tests and Release build, generate inputs reproducibly, confirm cache-path controls, and freeze exact source/object/module/compiler/helper/input/font/environment pins. Only then seek independent protocol review and an explicit quiet window. Estimated execution is approximately 3–4 minutes, subject to untimed preflight; no pilot timing or adaptive rerun is proposed. Report every phase, RSS and host-load sample, including adverse controls and unresolved intervals. No general recovery or memory claim is presumed.
